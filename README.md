# 🍕 Italian Pizza — Restaurant Website

A modern and responsive Italian pizza restaurant website designed for a fictional pizzeria.

The project focuses on a clean, natural visual style with warm colors, strong typography, and a simple user experience. It is designed to feel like a real local restaurant website rather than an overcomplicated template.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Clean Italian-inspired visual design
* Hero section with call-to-action buttons
* Featured pizza selection
* Interactive menu
* Pizza categories
* Restaurant information and story
* Image gallery
* Contact and location section
* Mobile navigation
* Smooth scrolling
* Interactive order counter
* Client-side contact form validation
* Subtle hover interactions

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript

No frameworks or unnecessary dependencies were used.

## 🎨 Design

The design uses a warm, understated color palette inspired by traditional Italian restaurants:

* Cream / off-white backgrounds
* Charcoal typography
* Muted dark red accents
* Subtle green details

The goal was to create a website that feels **natural, welcoming, and professional** without relying on excessive animations, gradients, or visual effects.

## 📱 Responsive

The website is designed to work across:

* Desktop
* Tablet
* Mobile
